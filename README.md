# Consumer Choice — Agent-Based Model (Mesa)

Project 1 of the course *Multi-Agent Systems and Simulation of Organizations*.

This repository contains a Python/Mesa 3 implementation of the **Consumer Choice** model
from the NetLogo Models Library (Jager & Wang, 2024), the baseline experiments, their
statistical analysis and the project report.

Current scope (tasks 1 and 2 of the project):

1. Analyse the model and run it with a basic setup that becomes the baseline.
2. Run the simulations for a large number of iterations to obtain statistics for the
   variables of interest.

## The model

Consumers linked in a social network choose between two products (orange and blue) whose
quality can change. Each tick, a consumer keeps its product by habit (probability equal to its
satisfaction), explores the other product, or chooses the product with the higher utility.
Utility combines the consumer's own experience, information from friends and the social norm
(share of friends using the product).

Outputs of the model (the only variables used in the analysis):

| Output | Definition |
|---|---|
| `orange` | Number of consumers using the orange product |
| `blue` | Number of consumers using the blue product |
| `clustering` | Mean share of friends that use the same product as the consumer |

## Repository structure

```
consumer_choice/model.py        model (agents, network, rules, outputs)
experiments/run_experiments.py  baseline and sensitivity experiments (Mesa batch_run)
analysis/analyze.py             statistics and figures
data/                           raw outputs of the experiments (compressed CSV)
results/figures/                figures used in the report
results/tables/                 tables and summary.json
report/                         report (Word, LNCS template) and the script that builds it
```

## How to run

Python 3.10 or later.

```bash
pip install -r requirements.txt
python experiments/run_experiments.py    # about 10 minutes on 2 cores; writes data/
python analysis/analyze.py               # writes results/
python report/build_report.py            # writes report/Report_Consumer_Choice_baseline.docx
```

A single run:

```python
from consumer_choice import ConsumerChoiceModel

model = ConsumerChoiceModel(rng=1)        # baseline parameters
for _ in range(1000):
    model.step()
print(model.datacollector.get_model_vars_dataframe().tail())
```

Each run uses a fixed seed, so the results are reproducible.

## Experiments

| Experiment | Parameter values | Runs per value | Ticks |
|---|---|---|---|
| Baseline | defaults of the original model | 1000 | 2000 |
| Norm | `norm_influence` = 0, 0.1, …, 1.0 | 100 | 1000 |
| Quality | `quality_blue` = 0.3, 0.4, 0.45, 0.5, 0.55, 0.6, 0.7 | 100 | 1000 |
| Exploration | `exploration` = 0, 0.01, 0.05, 0.1, 0.2 | 100 | 1000 |

Main baseline results at tick 1000 (1000 runs):

| Output | Mean | SD | 95% CI |
|---|---|---|---|
| Orange market share | 0.506 | 0.252 | 0.490–0.521 |
| Clustering | 0.937 | 0.031 | 0.935–0.939 |

## Extension: DIGI entry and learned prices (tasks 3-5)

The extended model (`consumer_choice/telecom.py`) applies the Consumer Choice decision rule
(habit -> exploration -> utility) to the Portuguese bundled-services market: MEO, NOS, Vodafone
and NOWO, which becomes DIGI in month 12. It adds prices, loyalty contracts (Lei 16/2022),
renewal decided by the consumer, a DIGI quality that improves with time, and a variable population.
With two operators and the extensions switched off it reproduces the baseline exactly.
The specification and the log of all decisions with their justification are in
`docs/model_v2_spec.md` (Portuguese).

| Step | Command | Output |
|---|---|---|
| Tests | `python tests/test_telecom.py` | regression vs baseline, contracts, policies |
| Pre-entry calibration | `python calibration/calibrate_pre_entry.py` | `results/v2/calibration_pre_entry.json` |
| Entry calibration | `python calibration/calibrate_entry.py [fine]` | `results/v2/calibration_entry*.csv` |
| Long-run check | `python calibration/calibrate_long.py` | `results/v2/calibration_long.json` |
| Price scenarios and bandit | `python experiments/run_pricing.py` | `results/pricing/*.csv*` |
| Analysis | `python analysis/analyze_pricing.py` | `results/pricing/figures`, `results/pricing/tables` |
| Mesa browser interface (SolaraViz) | `pip install "mesa[viz]"`, then `solara run visualization/app.py` | web page at http://localhost:8765 |
| Live view (NetLogo-style window) | `python visualization/live.py` | interactive window; `--gif out.gif` saves an animation |

The calibrated parameters are in `consumer_choice/calibrated.py`; the price policies
(fixed prices and the epsilon-greedy bandit) are in `consumer_choice/learning.py`.

## Report
